# Beotigi (버티기)

3인 하늘섬 생존 콘텐츠용 Paper 26.2 플러그인.

핵심 원칙: **UI 없음.** 퀘스트 창, 섬 안정도 게이지, 재해 카운트다운 같은 건 없다.
비가 오면 그냥 비가 오고, 점점 심해지고, 나무가 쓰러지고, 다리가 무너진다.
플레이어는 화면 구석 어디에서도 "폭풍까지 30초" 같은 걸 볼 수 없다.

## 요구 사항

- Paper **26.2** (build 121 이상 권장)
- **Java 25 이상** (Paper 26.x부터 Java 25 미만에서는 서버 자체가 뜨지 않음)
- Java/Maven 빌드: JDK 21 이상 (컴파일 타깃은 21 release)

## 빌드

```bash
mvn package
# target/Beotigi-1.0.0.jar 를 서버 plugins/ 폴더에 넣는다.
```

## 지금 들어있는 기능 (Phase 1)

기획서 전체(18개 섹션)를 한 번에 완성하는 건 비현실적이라, **"예고 없는 자연재해"**라는
콘텐츠의 핵심부터 실제로 동작하게 만들었다. 나머지는 아래 로드맵 참고.

- **날씨 격화 (`WeatherManager`)** — 비가 오면 조용히 `CALM → LIGHT_RAIN → STORM → SEVERE_STORM`
  단계로 격화/약화된다. 서버 관리자에게도, 플레이어에게도 현재 단계는 표시되지 않는다.
  - STORM 이상: 하늘에 노출된 플레이어를 바람으로 밀어냄, 나뭇잎/횃불/유리판 등 가벼운 블록 파괴
  - SEVERE_STORM: 근처 나무가 쓰러짐 (통나무가 `FallingBlock`으로 넘어감)
- **번개폭풍 (`LightningFireManager`)** — STORM 이상일 때 자연 번개 외에 추가 번개를 내리쳐서
  화재 확률을 높인다. 불이 나무 → 건물로 번지는 건 바닐라 화재 전파 그대로 사용.
- **폭우/침수 (`FloodManager`)** — 폭풍이 강할 때 농장 주변에 물이 차오른다. 일정 시간(기본 90초)
  후 자동으로 물이 빠진다.
- **운석 (`MeteorManager`)** — 밤에 아주 낮은 확률로 하늘에서 운석이 떨어져 크레이터를 만들고,
  중심에 희귀 광물이 담긴 상자를 남긴다. `/beotigi forcemeteor`로 테스트 가능.
- **공허 폭풍 (`VoidStormManager`)** — 아주 드물게 발생하는 후반부 이벤트. 섬 가장자리(공허에
  노출된 블록)가 지속적으로 사라진다. 총 삭제량에 안전 상한을 둬서 섬이 통째로 사라지진 않는다.
- **구조 붕괴 (`StructuralCollapseManager`)** — 지지대 없이 공중에 멀리 뻗은 다리/구조물을
  BFS로 탐지해서, 폭풍이 심할 때 가장자리 블록 몇 개를 무너뜨린다. 즉, **플레이어가 만든 다리를
  기둥 없이 길게 지으면 실제로 무너질 위험이 생긴다.**
- **시작 섬 3종 (`IslandManager`)** — `/island forest`, `/island rock`, `/island plains`로
  서로 다른 자원 구성의 시작 섬을 생성 (숲섬=나무, 바위섬=철/석탄 노출 광맥, 초원섬=농장+동물).
- **관리자 명령어** — `/beotigi status|forcestorm|forcemeteor|forcevoidstorm|stop|reload`
  (플레이어용 HUD가 아니라 순수 관리/디버그용 콘솔·운영자 명령어)

모든 수치(격화 확률, 침수 확률, 운석 빈도 등)는 `config.yml`에서 조절 가능. 플레이어에게는 노출되지 않음.

## 아직 없는 것 (Phase 2 로드맵)

기획서의 나머지 섹션들 - 각각 그 자체로 상당한 작업량이라 다음 단계로 분리:

- 화산섬 (연기 → 용암 → 폭발 단계적 진행)
- 새로운 섬 자연 발견 (정글/빙하/사막/버섯/폐허/성 등 다양한 테마, 이상적으로는 WorldEdit
  스키매틱 기반)
- 폐허/던전 (버려진 광산, 부서진 다리, 상자, 텍스트 없는 스토리텔링)
- 생태계 시뮬레이션 (쥐 증식, 벌 실종, 늑대-양 균형)
- 섬의 자연 성장 (나무 자람, 풀 확산, 연못 생성)
- 주민 자연 이주 및 마을 성장, 상점/시장 건물
- 하늘 항구, 떠돌이 상인
- 하늘을 나는 특수 생물 (하늘고래, 드래곤류, 거대 박쥐)
- 밤 이벤트 (붉은 달, 유성우, 안개, 박쥐 떼)
- 특수 아이템 (글라이더, 섬 연결석, 생명의 씨앗, 건설 코어, 바람의 깃털)
- 미니맵 — **서버 플러그인만으로는 진짜 미니맵을 그릴 수 없다.** Bukkit/Paper API는 클라이언트
  HUD를 렌더링할 방법이 없으므로, 실제로는 클라이언트 모드(Xaero's Minimap 등)나 BlueMap/Dynmap
  같은 별도 웹 지도 솔루션이 필요함. 이 저장소의 범위 밖.

## 알려진 제한

- Folia(멀티스레드 리전) 미지원. 일반 Paper 서버 기준으로 `BukkitScheduler`를 사용.
- 섬 좌표는 코드에 고정값(`IslandType`의 anchor)으로 박혀있음 — void 월드 생성 자체는
  이 플러그인이 하지 않으므로, 서버 관리자가 별도로 void 월드를 만들어야 함.
