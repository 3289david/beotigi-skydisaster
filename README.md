# Beotigi (버티기)

3인 하늘섬 생존 콘텐츠용 Paper 26.2 플러그인.

핵심 원칙: **UI 없음.** 퀘스트 창, 섬 안정도 게이지, 재해 카운트다운 같은 건 없다.
비가 오면 그냥 비가 오고, 점점 심해지고, 나무가 쓰러지고, 다리가 무너진다.
플레이어는 화면 구석 어디에서도 "폭풍까지 30초" 같은 걸 볼 수 없다.

## 요구 사항

- Paper **26.2** (build 121 이상 권장)
- **Java 25 이상** (Paper 26.x부터 Java 25 미만에서는 서버 자체가 뜨지 않음)
- Java/Maven 빌드: JDK 21 이상 (컴파일 타깃은 21 release)

## 빌드

```bash
mvn package
# target/Beotigi-1.0.0.jar 를 서버 plugins/ 폴더에 넣는다.
```

## 설치 가이드

1. **서버 준비** — [PaperMC 공식 사이트](https://papermc.io/downloads/paper)에서 26.2(build 121
   이상) 서버 jar를 받는다. `eula.txt`에 `eula=true`로 동의하고, `java -jar paper-26.2-*.jar`로
   한 번 실행해 기본 폴더 구조를 만든다. 실행 커맨드에 쓰는 Java는 **반드시 25 이상**이어야 한다
   (`java -version`으로 확인, 아니면 서버 자체가 기동하지 않는다).
2. **Void 월드 준비** — Beotigi는 하늘섬 지형 자체(빈 청크 제너레이터)는 만들지 않는다. 서버에
   이미 존재하는 월드에 섬을 "얹는" 방식이므로, 진짜 스카이블럭처럼 하려면 별도 월드 생성기
   (예: `Multiverse-Core` + `Multiverse-VoidGen`, 또는 `AsyncWorldEdit`의 void 프리셋 등)로
   빈 월드를 하나 만들고 그 월드에서 플레이하는 걸 권장한다.
3. **플러그인 설치** — `mvn package`로 빌드했거나 [Releases](../../releases)에서 받은
   `Beotigi-1.0.0.jar`를 서버의 `plugins/` 폴더에 넣고 서버를 (재)시작한다. 콘솔에 `[Beotigi]
   Beotigi 재해 시스템이 조용히 깨어났습니다.`가 뜨면 정상 로드된 것이다.
4. **시작 섬 생성** — 각 플레이어가 원하는 월드에 들어가서 아래 중 하나를 실행한다 (숲/바위/초원
   3인이 서로 다른 걸 고르는 걸 권장):
   ```
   /island forest
   /island rock
   /island plains
   ```
5. **(선택) 클라이언트용 미니맵** — 서버 쪽엔 미니맵 렌더링 기능이 없다. 녹화용 클라이언트에
   [Xaero's Minimap](https://www.curseforge.com/minecraft/mc-mods/xaeros-minimap) 같은 모드를
   설치하면 서버 설정 없이 바로 동작한다.
6. **동작 확인** — 관리자 권한으로 `/beotigi status`를 입력해 현재 날씨 단계 등이 뜨는지
   확인한다. 필요하면 `/beotigi forcestorm`, `/beotigi forcemeteor` 등으로 재해를 강제
   발동시켜 테스트할 수 있다 (아래 "관리자 명령어" 표 참고).

## 들어있는 기능

기획서의 18개 섹션을 전부 구현했다. 모든 수치(격화 확률, 발생 빈도 등)는 `config.yml`에서
조절 가능하며, 어떤 값도 플레이어에게는 노출되지 않는다.

### 날씨 & 재해
- **날씨 격화 (`WeatherManager`)** — 비가 오면 `CALM → LIGHT_RAIN → STORM → SEVERE_STORM`
  단계로 조용히 격화/약화. STORM 이상에서 바람이 밀어내고 가벼운 블록이 날아가며,
  SEVERE_STORM에서는 나무가 실제로 쓰러진다.
- **번개폭풍 (`LightningFireManager`)** — STORM 이상일 때 추가 번개. 화재는 바닐라 전파 그대로.
- **폭우/침수 (`FloodManager`)** — 폭풍이 강할 때 농장이 침수, 시간이 지나면 자동으로 빠짐.
- **운석 (`MeteorManager`)** — 밤에 드물게 낙하, 크레이터 + 희귀 광물 상자.
- **유성우** — 운석의 "약한 버전"이 짧은 시간에 여러 번 떨어짐 (밤 이벤트로 트리거).
- **공허 폭풍 (`VoidStormManager`)** — 후반부 이벤트. 섬 가장자리 블록이 사라짐 (안전 상한 有).
- **구조 붕괴 (`StructuralCollapseManager`)** — 기둥 없이 뻗은 다리/구조물을 BFS로 감지해서
  폭풍 중 실제로 무너뜨림. 플레이어가 만든 구조물에 반응하는 재해.
- **화산 (`VolcanoManager`)** — 화산섬은 `휴면 → 연기 → 소규모 용암 → 폭발 → 냉각` 주기를
  스스로 반복한다. 폭발 시 용암탄이 주변 섬까지 날아가 불을 낼 수 있다.
- **밤 이벤트 (`NightEventManager`)** — 매일 밤 시작 시 한 번, 독립적으로 굴림:
  - 붉은 달: 근처에 적대 몹이 갑자기 몰림 (마인크래프트 자체엔 달 색을 바꾸는 API가 없어서
    시각 효과 대신 몹 압박으로 구현 - 아래 "알려진 제한" 참고)
  - 유성우, 이상한 안개(어둠 효과 + 안개 파티클), 거대 박쥐 떼

### 섬 & 발견
- **시작 섬 3종 (`IslandManager`)** — `/island forest|rock|plains` (숲=나무, 바위=광맥, 초원=농장+동물).
- **새로운 섬 발견 (`IslandDiscoveryManager`)** — 10분마다 확률적으로, 스폰에서 먼 곳에
  9종 중 하나가 나타난다: 정글 / 빙하 / 사막 / 화산 / 꽃 / 버섯 / 광산(전리품 상자) /
  폐허(부서진 벽 + 상자) / 성(더 크고 값진 전리품). 텍스트 설명 없음 - 직접 가서 확인.
- **생태계 (`EcosystemManager`)** — 토끼(=쥐 컨셉, 바닐라가 이미 당근을 갉아먹음)가 늘어나고,
  근처에 벌이 없으면 작물 성장이 가끔 멈추고, 양이 너무 많아지면 야생 늑대가 나타나 사냥한다.
- **자연 성장 (`IslandGrowthManager`)** — 꽃이 퍼지고, 웅덩이 지형에 작은 연못이 생기고,
  초원에 동물이 천천히 늘어난다.

### 주민 & 교역
- **주민 이주 (`VillagerMigrationManager`)** — 침대+문이 있는 "집"을 감지하면 주민이 자연스럽게
  찾아온다. 마을이 일정 규모(기본 4명)를 넘으면 그 중 일부가 직업(대장장이/농부/사서 등)과
  실제 작업대(용광로/작곡가/서고 등)를 갖는다 - 이게 곧 "HUD 없는 상점"이다 (바닐라 주민 거래 UI 활용).
- **떠돌이 상인 (`TravelingMerchantManager`)** — 아무도 부르지 않았는데 가끔 나타나, 특수
  아이템을 포함한 희귀 거래를 남기고 일정 시간 후 사라진다.

### 생물 & 아이템
- **하늘 생물 (`SkyCreatureManager`)** — 스케일을 키운 가스트("하늘고래"), 팬텀("거대한 새"),
  박쥐 무리("거대 박쥐 떼")가 가끔 등장. 사냥 대상이 아니라 그냥 세계에 존재하는 생물.
- **특수 아이템 (`SpecialItemManager`)** — 운석/폐허/성/상인에서 발견:
  - 🪁 글라이더 (엘리트라 리스킨, 공허 위 활공)
  - 🧲 섬 연결석 (가장 가까운 미지의 섬까지 임시 다리를 놓음)
  - 🌱 생명의 씨앗 (반경 3칸의 죽은 땅을 되살림)
  - 🏗️ 건설 코어 (딛고 선 땅을 반경 3칸 넓힘)
  - 🌪️ 바람의 깃털 (강풍 속에서 슬로우 폴링 + 상승기류 효과)

### 관리자 명령어 (플레이어용 HUD 아님, 순수 디버그용)
```
/beotigi status|forcestorm|forcemeteor|forcevoidstorm|forcevolcano
          |forcediscovery [type]|forcemerchant|forcecreature [whale|bird|bats]
          |forcenightevent [shower|bats]|give <item>|stop|reload
```

## 알려진 제한

- **미니맵** — 서버 플러그인만으로는 진짜 미니맵을 그릴 수 없다 (Bukkit/Paper API는 클라이언트
  HUD를 렌더링할 방법이 없음). **Xaero's Minimap 같은 클라이언트 모드는 서버 쪽 코드 없이도
  그대로 작동**하니, 녹화용 클라이언트에 설치하는 것으로 이 요구사항을 충족하는 걸 권장한다.
  BlueMap/Dynmap 같은 웹 지도도 대안.
- **붉은 달 시각 효과** — 달 텍스처/색상을 바꾸는 공식 API가 없어서, "붉은 달"은 시각적 변화
  대신 몹 압박(적대 몹 급증)으로 구현했다. 리소스팩을 곁들이면 진짜 색도 바꿀 수 있다.
  안개도 마찬가지로 `DARKNESS` 포션 효과 + 파티클로 근사했다 (실제 클라이언트 렌더 안개는
  리소스팩/셰이더 영역).
- **섬 이동(자석돌)** — 건물이 이미 있는 섬 전체를 물리적으로 옮기는 건 너무 파괴적이라,
  "미지의 섬까지 임시 다리를 놓는다"로 안전하게 재해석했다.
- Folia(멀티스레드 리전) 미지원. 일반 Paper 서버 기준으로 `BukkitScheduler`를 사용.
- 상태는 대부분 메모리에만 저장된다 (발견된 섬 목록, 화산 진행 단계 등). 서버 재시작 시
  초기화됨 - 장기 녹화라면 재시작을 피하는 걸 권장.
